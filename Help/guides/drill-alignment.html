Drill alignment

Land the holes, the slots and the board outline on copper that is already there.

A 0.8 mm hole in a 1.6 mm pad leaves a ring of copper 0.4 mm wide. Set work zero 0.3 mm out, and one side of that ring is down to 0.1 mm.

This guide finds that error by looking at it, with the spindle off, before anything is drilled. Bring the bit down just above a real pad, jog it to the middle of the pad, and type the two numbers the machine shows. When the test lands dead centre on its own, write the files again with that correction built in. Two or three tries is usually enough.

When to use it

StepUse it?Why
Top and bottom copper No These make the copper. There is nothing on the board yet to line up with; they are what everything after them lines up to.
Drilling and slots Yes The holes have to land in pads that are already on the board, however they got there, and especially if the board has been off the machine since.
Board outline Yes The outline has to go round the same copper. If the board was unclamped after drilling, test again before cutting it out.

If the board never left the machine after the copper was cut and work zero was not touched, the holes should already line up. One test at 0, 0 confirms it in a minute.

Before you start

  • The board is clamped for this step, as square to the machine’s X and Y axes as you can get it.
  • X and Y work zero are set where this project always has them: the stock’s lower-left corner if the project cuts stock to size, otherwise the board’s.
  • The bit for this step is fitted (the drill for drilling, the end mill for the outline), and Z is zeroed on your usual spot.
  • You have something to look closely with: a loupe, a phone camera zoomed in, or a USB microscope. A tenth of a millimetre is easy to see up close and hard to see from standing height.

What the test does

The test file cuts nothing. With the spindle off, it:

  1. rises to safe height,
  2. moves over the hole you chose, plus any offset you have entered,
  3. comes down quickly to 1 mm above the stopping height, then slowly the rest of the way,
  4. stops 0.1 mm above the surface (or whatever Stop above the surface is set to) and stays there.

Where it aims. For a hole, the centre. For a slot, the middle of the slot: halfway along its length and halfway across its width. The dialog lists each one as Hole or Slot, with the position it aims at.

If the bit touches the copper, stop the machine. Z zero is below the surface. Zero Z again and rerun the test. The last millimetre is slow to give you time to stop it.

Step by step

1Open the dialog

Job › Drill alignment… It works from the project as it stands; you do not need to have exported first.

Check Files go to. The test file and the aligned files are written there. By default that is the folder you last exported to; Change… picks another. A long path is shortened in the middle: hover over it to see all of it, or widen the window.

2Pick a file and a hole

Test with lists every drilling and slot file the project writes. Hole lists what is in the chosen file, in the order the file reaches them. Pick a pad you can see clearly. It does not matter which file you test with: the offset you find goes into all of them.

The line under the file name says which bit that file uses. At the outline step, leave the end mill in and pick any hole that has already been drilled.

3Test where the program thinks the hole is

The two boxes already hold the hole’s own coordinates, so leave them alone and press Write test. The file is YourProject.align-test.nc. Open it in your sender and run it.

4Look, and measure

If the tip sits dead centre, you are done: the files as exported already line up, and there is nothing to write. Otherwise, work out how far the tip has to travel to reach the centre, in X and in Y.

When the test has finished the machine is idle, so the jog controls work.

  1. Jog X and Y only, in 0.01 mm steps, until the tip sits on the centre. Leave Z where it is, or raise it a little first if the board is not flat. Raising Z does not change X or Y.
  2. Read the work position in your sender. That is where the hole really is.

5Type where it really is, and test again

The two boxes, It is really at X and It is really at Y, start out holding the position the test just used — where the program thinks the hole is. Replace them with the numbers you just read off the machine. There is nothing to add up and nothing to subtract: the dialog works out the correction and shows it underneath, so you can see at a glance whether it is the few hundredths you expect. 

                          X          Y
The test sent the bit to  55.625     58.305
You jogged it to          55.795     58.255     <- type these two
                          ------     ------
The dialog says           +0.170     -0.050     <- and works this out

Press Write test again. It overwrites the same file, so reload it in your sender (most senders keep the copy they first opened), then run it: this time it should go straight to the middle of the hole.

There is no need to send the head back to 0, 0 between tests. Every test rises to safe height first and then moves straight to the hole.

Repeat until you are happy with it. The dialog keeps your numbers until you close MillBurn, so closing and reopening the dialog in between loses nothing.

6Check a hole on the far side

Pick a hole near the opposite corner of the board. Its boxes fill with its own coordinates plus the correction you have just found, so pressing Write test sends the bit where that hole ought to be. If it lands centred there too, the correction is right everywhere on the board.

If it is out by a different amount, the board is sitting at an angle. An offset moves every hole by the same amount, so on its own it cannot correct that — but a second measurement can. Either square the board up and start again from step 3, or measure that far hole properly and let the turn be worked out: measuring a second hole, below.

7Write the aligned files

Press Write aligned files. Everything ticked under Write again, aligned is written again with the offset built in — drilling, slots and the board outline, unless you have changed the ticks (see choosing what gets written again). The dialog closes. For the test board, that is:

FileWhat it is
Millburn_Test_Board-PTH-drl.bit1-1.00mm.aligned.nc
…-PTH-drl.bit2-0.50mm.aligned.nc, …bit3…		 Drilling, one file per bit, as usual
…-PTH-drl.slots.aligned.nc
…-NPTH-drl.slots.aligned.nc		 Routed slots and milled holes
…-Edge_Cuts.aligned.nc The board outline, while it is ticked
…-PTH-drl.drilling.aligned.html
…slots.aligned.html		 The pages that go with them, listing the aligned files

The copper files and the stock are never moved. The copper is what you lined everything up with, and the stock is cut before there is any copper on it.

Each aligned file says so near the top:

( Aligned with the drill alignment test: every move shifted X+0.170 Y-0.050 mm from the plain export. )

8Run the aligned files

Run the .aligned.nc files instead of the originals, in the order the drilling page suggests. Change bits and set Z as you normally would. X and Y zero stay where they are, and the offset is already in every file, so you do not need to test again for each bit.

Consider moving the original, un-aligned files into another folder, so that neither you nor your sender’s recent-files list can pick one by mistake.

The stock’s waste holes

If the project cuts its own stock, tick Alignment holes in the waste under Project info and the stock program puts two small holes in the borders that get thrown away — one near the right-hand end of the bottom border, one near the top of the left. They are cut in the same program, in the same setup, with the same end mill as the stock’s edges, so their positions are not measured at all: they are exactly where the file says, in the frame every other program is written in.

Tick Use the stock’s two waste holes in the alignment dialog and the hole lists show those two instead of the board’s. Three things make them worth using:

  • They exist before anything is drilled. A board hole can only line up a step that comes after drilling. The waste holes can line up the drilling itself.
  • They are nearly the stock’s diagonal apart, which is a longer baseline than almost any pair of board holes — and the turn’s accuracy is the error in reading each hole divided by the distance between them.
  • They survive. They are holes in a piece of copper-clad: an etch, a re-clamp, a coat of paint and a trip to the other machine all leave them exactly where they were. Then they are cut off with the waste.

Fit the end mill that cut them — the dialog names it — rather than a drill, and hover over them the same way as any other hole.

Working on the other side

The waste holes go right through, so the same two can be used with the board turned over. Tick The board is flipped over, and I am measuring from the back: the hole positions mirror about the stock’s vertical centreline, which is the axis the app mirrors a bottom-side program about and the only one that puts the stock back in the same corner. The list shows the mirrored coordinates, and the test program sends the bit to them.

Because the two holes are deliberately not symmetric — one low and right, one high and left — a board that went back the wrong way up shows itself: the numbers come out large instead of a few hundredths.

Choosing what gets written again

The list under Write again, aligned is every G-code program this export writes, one tick each. Drilling, routed slots and the board outline start ticked. The copper does not, because on a first side the copper is the thing you measured against — moving it would move the target along with the correction.

On a flipped board that changes. Cut the top copper, etch it, turn the stock over, and the bottom copper is now the program that has to land on what is already there. Tick it. This is what the list is for: which programs have to follow the board depends on the workflow, and MillBurn cannot know yours. Programs written for the flipped side are marked flipped side in the list, and if the ticks disagree with the flip box — a correction measured face-up being written into a bottom-side program, or the other way round — the dialog says so rather than writing it quietly.

The stock is never in the list. It is cut before there is anything on the board to line up with, and it is the work zero the correction itself is measured from.

Measuring a second hole, when the board is not square

Everything above assumes the board sits square to the machine, so that one hole put right puts every hole right. Sometimes it does not: a jig with a little play in it, or a board clamped back down after etching, can sit a fraction of a degree over. At the hole you measured, that looks exactly like an offset — it is the holes at the other end of the board that come out wrong, and by more the further away they are.

A quarter of a degree is 0.3 mm across a 70 mm board. That is a hole off the edge of its pad, from an error too small to see at the hole you were looking at.

Tick Measure a second hole as well, to correct rotation. A second hole row appears, already set to the hole furthest from the first one, with its own Write test button. Then:

  1. Leave the first hole’s numbers as you measured them in steps 3 to 5.
  2. Press Write test on the second row, run that file, and jog until the tip sits dead centre over that hole.
  3. Type what the machine says into the second row’s It is really at X and It is really at Y. Each row is read against its own hole, so the second row is not a correction to the first — nothing carries over between them.

The line under the second row then tells you what the two measurements came to: 

The board is turned 0.2618° anticlockwise, and the two holes measured +0.010 mm against their known distance apart. Every hole is moved to match.

The two test files are written under separate names — ….align-test-first.nc and ….align-test-second.nc — so there is no way to run one thinking it is the other.

The distance check

Two holes are a known distance apart, and you have just measured that distance. Copper-clad does not stretch, so if the two disagree, one of the holes was read wrongly — the wrong hole in the list, or a number off the wrong axis. A few hundredths is measurement. More than half a millimetre and MillBurn will not write the files at all; it says what the two distances were, and you can measure again.

The same goes for two holes close together: below 10 mm apart, a hole read a hundredth out swings the angle more than the angle itself, so it asks for two holes at opposite ends of the board instead of answering with a number it cannot stand behind.

What comes out

The same files as before, with the turn built into every coordinate rather than applied by the machine — GRBL has no coordinate rotation of its own. Circles stay circles; the arcs are turned along with everything else. The header says both halves of what was done: 

( Aligned with the drill alignment test: every move turned 0.2618 degrees about X23.620 Y47.878 mm, then shifted X+0.170 Y-0.050 mm, from the plain export. )

The turn is taken about the first hole you measured, so that hole lands exactly where you put it and the rest of the board follows the angle.

Worth knowing

  • The correction is saved with the project. Write the aligned files and the shift, the turn and the date are kept in the project file. Next time you open the dialog it offers them back with Use it, so a board that is still clamped where it was does not have to be measured again. If the board has moved since, ignore it and measure: the date is shown for exactly that decision. A plain Export still writes plain files — the aligned ones come from this dialog, or from --align on the command line.
  • The outline step, after re-clamping. If the board came off the machine after drilling, run the test again with the end mill fitted, over a drilled hole. Writing the aligned files again rewrites the drilling files too, with the new offset. Once the drilling is done that makes no difference: run only the outline.
  • Stop above the surface is remembered between sessions. 0.1 mm is close enough to judge the centre by eye, and high enough that a Z zero a few hundredths out does not put the tip into the copper.
  • From the command line: align <project> --hole 3 --offset 0.17,-0.05 writes the test file, and export <project> --align 0.17,-0.05 --align-outline --write writes the aligned files. Adding --hole2 11 --offset2 -0.02,0.03 to the align command works out the turn from two measured holes and prints the export line to run, and --align saved uses the correction already kept in the project.
