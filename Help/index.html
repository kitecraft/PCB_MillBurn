The short version

  1. Import a Gerber folder — everything your EDA tool exported, drill files included. Roles are read from the files themselves; anything guessed is labelled.
  2. Set each layer’s output in the board pane — grouped by top side, inner layers, bottom side, and holes and outline. G-code for the mill, SVG for the laser, or nothing. Each one becomes its own file.
  3. Preview (F5) draws the emitted programs back over the board — parsed from the G-code itself, not from the toolpaths that made it.
  4. Export (Ctrl+E) shows every file, what it will do, and anything worth checking, before a single byte is written. You choose the folder; the names come from the layers.

Run order on the machine: isolate, drill, cut out — with the stock cut to size first, when the job is built on stock. Work zero is the board’s lower-left corner, or the stock’s, and every file in an export shares it.

Two things worth doing before you cut

Both are optional, both are ticked in the Export window, and between them they account for most of the boards people ruin.

Run it in the air first

Tick Also write a dry run of each program. Every .nc gets a .dryrun.nc beside it that traces exactly the same path, held 5 mm above work zero, with the spindle never started. Set work zero as you would for the real job, run the dry one, and watch.

It answers the questions that otherwise cost a board: is work zero where you think, does the job fit on the stock, will it reach a clamp, which side of the line is the cutter on, and how long is this actually going to take — the feeds are kept, so it takes as long as the real thing. More ›

Measure the board and follow it

Isolation cuts 0.05 mm deep. An ordinary piece of clamped copper-clad is 0.1–0.2 mm out of flat. That comparison is the single most common reason PCB milling disappoints people, and no amount of care with the toolpath fixes it.

  1. Job › Write probing routine… and run it in your sender.
  2. Job › Import height map… with your sender’s log.
  3. Export with Level to the imported height map ticked.

Each program gets a .levelled.nc whose depth follows the measured surface. Work zero has to be in the same place when you cut as when you probed — and when a tool change or a second program forces you to set Z again, touch off on the same spot every time. The map records heights relative to where Z zero was, so zeroing on a different high spot shifts every correction in it by the same amount. More ›

If your sender’s preview of the probing file shows no Z movement, or the tool dragging across the board at depth, that is the viewer not understanding G38.2 — the file is correct and cuts nothing. More ›

Mask relief needs this one. Cured soldermask is 0.02–0.04 mm thick — thinner than the flatness of ordinary stock — so without a height map the same program leaves mask on one pad and cuts into the copper of another, and neither shows up until the board is under a light.

Also worth knowing

  • Drilling is one file per bit, with a page of its own. A layer that needs three bits is three files, and the HTML page beside them lists them in the suggested order, with the bit and hole count for each. Fit the bit and set Z before each file; X and Y keep their zero. When the holes have to land on copper that is already there, the drill alignment guide lines them up first.
  • The board pane has two toggles per layer, not one. The checkbox draws the artwork; the zig-zag beside it draws the toolpath that layer becomes. They are separate because the copper hides the cuts — turning one off and the other on is how a toolpath becomes readable. The pill on the right says what the layer is being exported as, so a collapsed drawer still answers it.
  • You can open any G-code file and look at it. File › Open G-code, or drag a .nc onto the window. Not only ours — the viewer reads emitted text rather than the toolpaths behind it, so a program from any CAM tool draws the same way. It is also how you look at the dry runs and levelled files.
  • Your machine can have its own start and end lines. Edit › Start and end G-code. Homing, a work offset, a vacuum relay, a spindle dwell — whatever yours needs, added to every program, checked as you type.
  • Double-sided boards line up without measuring anything. The recipe is drilling before you flip, and pinning through the holes you already made. It reaches 20–50 µm and needs no fiducials, no probe and no arithmetic — but it does put one rule on your design, so read it before you lay the board out.

What this app does not do

It writes files. It never opens a serial port, never drives a machine, and never needs to know what controller you have. You load its output into whatever sender you already use — gSender, UGS, Candle, LightBurn, LinuxCNC — exactly like any other program.

That boundary is the reason it works with every controller that has ever existed, and it is not going to move. It is also why probing is generate and import: the app writes the routine, your sender runs it, and the log comes back here. A map probed months ago, by a tool that has never heard of this one, imports just as well.
