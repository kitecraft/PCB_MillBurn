PCB_MillBurn help
Gerber to G-code for the mill, SVG for the laser.

Shipped with the app and opened from the Help menu. No network needed — this works next to a machine on a computer that has never been online.

The short version

  1. Import a Gerber folder — everything your EDA tool exported, drill files included. Roles are read from the files themselves; anything guessed is labelled.
  2. Set each layer’s output in the Layers drawer. G-code for the mill, SVG for the laser, or nothing. Each one becomes its own file.
  3. Preview (F5) draws the emitted programs back over the board — parsed from the G-code itself, not from the toolpaths that made it.
  4. Export (Ctrl+E) shows every file, what it will do, and anything worth checking, before a single byte is written. You choose the folder; the names come from the layers.

Run order on the machine: isolate, drill, cut out. Work zero is the board’s lower-left corner, shared by every file in an export.

Nothing here has been verified by cutting air first. A dry-run generator — the same program with the Z moves lifted clear — is planned but not built. Until it exists, the first time a program runs, it runs into copper. Check the preview, and consider running the first job on scrap.

What this app does not do

It writes files. It never opens a serial port, never drives a machine, and never needs to know what controller you have. You load its output into whatever sender you already use — gSender, UGS, Candle, LightBurn, LinuxCNC — exactly like any other program.

That boundary is the reason it works with every controller that has ever existed, and it is not going to move.
